# Site Murgueço

Uma página informativa sobre morcegos, criada com o intuito de desmistificar e ensinar sobre esses fascinantes "ratos de asa". O projeto foi desenvolvido utilizando HTML5, CSS e Bootstrap 5.

## 🦇 O que é o projeto?

O Murgueço é um site educacional de página única (Single Page Application - SPA) focado em apresentar informações biológicas, curiosidades e desmistificar lendas sobre os morcegos. O conteúdo abrange desde as características físicas e tipos de alimentação até dicas de convivência pacífica com esses animais.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica do site.
* **Bootstrap 5:** Framework CSS para responsividade, estilização de componentes (Navbar, Cards, Carousel, Accordion, Alerts e Popovers) e grid system.
* **JavaScript:** Utilizado para a funcionalidade dos componentes interativos do Bootstrap (como os popovers e o menu mobile).
* **CSS Customizado:** O projeto prevê um arquivo CSS externo (`css/bootstrap.min.css`) para eventuais ajustes e estilizações específicas de cores (como as classes `.bg-orange` e `.text-orange`).

## ⚙️ Funcionalidades

* **Navegação:** Menu superior responsivo com links âncora para as seções da página.
* **Seção Informativa:** Descrição sobre o que são morcegos, incluindo anatomia, ecolocalização e visão.
* **Tipos de Morcegos (Cards):** Uma grade de cartões ilustrados apresentando os diferentes hábitos alimentares (Insetívoro, Frugívoro, Nectarívoro, Carnívoro e Hematófago).
* **Galeria de Imagens (Carousel):** Um carrossel interativo exibindo diversas fotos de morcegos.
* **Lendas e Mitos (Accordion):** Uma seção expansível que explora mitos de diferentes culturas (Maia, Folclore Europeu e Mitologia Grega).
* **Alertas e Curiosidades (Popovers):** Botões interativos que, ao serem clicados, exibem informações adicionais sobre os motivos pelos quais os morcegos não atacam pessoas e como combatem pragas.
* **Dicas de Prevenção (List Group):** Uma lista clara e formatada com orientações para evitar a presença indesejada de morcegos em áreas residenciais.

## 🛠️ Como executar o projeto

Como é um site estático, basta abrir o arquivo `index.html` em qualquer navegador web moderno. 

**Pré-requisitos:**
Certifique-se de que a estrutura de pastas do seu projeto está correta para que as imagens e os arquivos do Bootstrap sejam carregados perfeitamente:
* As imagens devem estar dentro de uma pasta chamada `img/`.
* Os arquivos CSS devem estar em `css/` e os scripts JS em `js/`.
